## Selected projects

**exchange-data-ops-lab**  
Async Python market-data pipeline with Binance WebSocket ingestion, SQLite storage, microstructure features, data-quality checks, Prometheus/Grafana-ready metrics, and statistical edge validation.  
https://github.com/Mohsentinal/exchange-data-ops-lab

**lob-replay-engine**  
C++20 limit-order-book replay engine with deterministic L2 market-data reconstruction, invariant checks, CSV metrics, checksum validation, CMake, tests, CI, and benchmarking.  
https://github.com/Mohsentinal/lob-replay-engine

**alpha-exec-stack**  
Microstructure research pipeline on Binance BTCUSDT: WebSocket ingest, feature engineering, labels, GBM experiments, and maker/taker evaluation.  
https://github.com/Mohsentinal/alpha-exec-stack

**wfv-toolkit**  
Walk-forward validation toolkit with purge/embargo support for time-series machine learning.  
Install: `pip install wfvkit`  
https://github.com/Mohsentinal/wfv-toolkit

**consistency-auditor**  
CLI tool for comparing backtest and live trading logs to detect drift, slippage, and execution mismatches.  
https://github.com/Mohsentinal/consistency-auditor
